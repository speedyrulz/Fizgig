**Fix: Krea 2 runs that failed before the first step on some Windows PCs.** On some PCs, often ones with an older Visual Studio 2019, Compile Blocks couldn't build its code and the run stopped at step 0 with a `returned non-zero exit status 2` error. Fizgig now tries a quick test compile first. If it fails, the run trains uncompiled, and the log says what to install for full speed: Visual Studio 2022 Build Tools (https://aka.ms/vs/17/release/vs_BuildTools.exe) with "Desktop development with C++" ticked, then restart Fizgig.
