# Fizgig v8.3.0: Studio

**H3 Speed Boost:** a new tick on H3's Clip row, on by default. The first half of the steps render at half size, then the clip grows to full size for the rest, so clips render faster. A seed frames a little differently with it on; untick it to see a seed exactly as a full-size render gives it. It's SPEED (Xiao, Chao, Yariv and Wetzstein, 2026) by way of @lonecatone23's LC Speed Boost.

**Freeze and roll each slider on its own:** every donor slider now has its own padlock, so a block's primary and donor sliders lock, freeze and roll separately. **Primary / Donor / Both** picks which sliders a roll changes, and **Roll** counts sliders.

**Smaller changes:**
- With a donor loaded, the Tweaked caption says it includes the donor.
- Keep in view hides its clips while you resize the panel, so dragging stays smooth.
- H3's Render size menu and No-LoRA clip are gone: clips render at the Width and Height you set, and the base-model render no longer slows the loop.
- H3's Sound, Speed Boost and Show early ticks are spaced apart.
