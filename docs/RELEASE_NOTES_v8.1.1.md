# Fizgig v8.1.1: edits with extra reference pictures

**Edit LoRAs can bring in more pictures.** On Flux 3 Image Klein and Klein 9B, an edit can use extra reference pictures beside each original: another person, an object or a place to bring into the edited photo. Put them in the Originals folder next to the original, named `photo_1.png`, `photo_2.png` … for `photo.png`. They can be any shape; only the original has to match the edited photo's crop. Flux 3 takes up to 9 extra pictures per edit, Klein up to 3. Suggested by @V1sionVerse, with a +1 from @Galvo87 (#187). Qwen Image 2.1 is next.
